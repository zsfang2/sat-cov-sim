# 条件质量事件

接口位于 `satellite_coverage.engine.quality_events`。M1 的单条候选链路可以通过 `DirectLinkEvaluator` 在指定时刻直接计算，再由 `direct_events` 生成事件。现有几何展示窗口接口保持原样。

```python
from satellite_coverage.engine.quality_events import DirectLinkEvaluator, direct_events

candidate = DirectLinkEvaluator(link_config, catalog, terrain=terrain_context)
result = direct_events(
    {candidate.candidate_id: candidate},
    candidate_identities={candidate.candidate_id: candidate.identity},
    start=link_config["start"], end=link_config["end"],
    step_s=20, max_probe_step_s=1, event_tolerance_s=.05,
)
```

`terrain` 可省略；`catalog` 仅 TLE 输入需要。多候选使用不同 ID 的 evaluator 字典；不能先按服务星筛掉其他候选。无候选的观察区间仍保留在总时长里，其传播机会不可用。

## 状态与事件口径

- 几何层要求仰角严格大于 0° 且不低于配置的 minimum_elevation_deg；输出 visible/invisible/unknown。
- 质量层在几何可见、候选记录 computed 且裕量 Quantity 已知时比较 margin>=0，输出 sufficient/insufficient；几何不可见另列 invisible，未计算/失败/未知另列 unknown。原记录和原因全部保存。
- `candidates[id]` 包含几何与质量窗口、逐段状态、各状态累计秒数、最长连续秒数、采样到的门限等值时刻。几何不可见时长不会混入已知裕量不足时长。
- 多候选机会在每个时间段上合并：至少一条已知足够则 available；否则存在未知则 unknown；其余 unavailable。以区间合并防止两个端点分别由不同卫星满足门限时误称全段连续可用。
- 机会只表示给定模型下可能有候选链路，不保证即时切换、波束、容量或实际服务。service_eligibility 始终 unknown；每个原链路的地形有限范围契约保留。

## 时间求值与误差限制

所有时间必须带时区。初始固定步长网格含两个观察端点；算法在所有相邻间隔中增加直接中点求值，直到间隔不超过 max_probe_step_s，并对任一候选的几何/质量状态变化进一步求值到 event_tolerance_s。新增时间调用全部候选的 evaluator，不对旧功率或旧轨道序列插值。异常求解保留为 failed 记录；非法记录身份/时间/单位拒绝。

两个端点状态相同的区间采用“其间状态不变”的采样假设。状态不同的最终小区间记为 transition_bracket/unknown，保留左右状态及时间；不把中点或线性插值的根包装成精确事件。已知窗口的相邻变化区间以 start/end_bracket_utc 给出。门限恰好相等的孤立采样记录为 contact，不产生人为正时长窗口；一段连续的零裕量按 >=0 处理。

event_tolerance_s 仅约束已检测变化的时间包围宽度。小于探测间隔的窄窗、两点之间的切触或短缺测可能未被发现；有限次采样没有全连续域保证。真实完整过境仍需 E3 步长收敛和误差检查，业务 allowed_event_error 保持 undetermined。

`summarize_events` 可处理已有的不规则时间序列，但不增加求值。必须传入完整候选列表、含首尾的严格递增时间序列和 max_gap_s。缺少的候选样本转换为显式 unknown；超过 max_gap_s 的间隔全部未知。已有序列两端状态不同也保持未知，不能声称直接细化。累计量按区间秒数求和，绝不以帧数比例替代；unknown 报告独立分母。

窗口接触观察区间边缘时 start/end_clipped 为真；接触缺测边缘时记录 unknown_interval 截尾。相邻直接变化区间给出边界包围而非缺测截尾。未知会分隔已知窗口，所以最长连续时长是采样条件下已支持的时长，不隐式跨缺失连接。

## M1 接口与资源

`calculate_links(..., evaluation_times=[ISO时间,...])` 为 TLE/fixed_ecef 提供显式直接求值。时间必须在原请求内且严格递增；TLE 仍按原始 start 选择并按原 start/end 检查最大历元偏差，细化不能改变轨道元素政策。原采样路径输出保持不变。direction_sequence/relative_enu_sequence 不能在新时刻直接求值，接口拒绝插值；有解析轨迹时可自行提供明确身份的直接 evaluator。

默认最多 100001 个唯一时间点，配置不得超过该上限。初始网格预算预检，细化时继续检查；超限抛错，不返回冒充完整的事件结果。总候选求值次数为唯一时刻数×候选数，应按场景选择上限。时间控制按微秒量化并写入结果。保存 settings、候选身份、全部输入记录校验和与 run_checksum；caller 提供的自定义 evaluator 必须如实声明身份和直接求值方式。
