# M3：局部 DEM 剖面、GeoTIFF 接入与 M1 联动

更新：2026-09-30。已在核心剖面基础上接入 GeoTIFF、EGM2008 转换和 M1 链路，完成受控场景及一次有明确假设的真实数据联动；不增加 demo，**尚未宣告 M3 完整验收**。

## GeoTIFF、高程转换与来源

`data_sources.terrain_dem.load_terrain_dem()` 要求文件 SHA-256、高程单位、垂直基准、DSM/DTM/人工表面类型和来源说明。接受米制 WGS84 椭球高，或配有明确本地 geoid 网格的 EGM2008 正高；其他/未知高程基准拒绝执行。

用户确认中国数据来源为 Copernicus DEM GLO30-CHINA。根据 [官方产品说明](https://dataspace.copernicus.eu/explore-data/data-collections/copernicus-contributing-missions/collections-description/COP-DEM)，该产品采用米制 EGM2008 高程，属于包含建筑和植被的 DSM。当前本地拼接文件哈希已复核，但原始瓦片版本及拼接时是否进行过高度转换仍未独立复原。因此真实实验明确以“本地文件保留原产品高度基准”为条件，不声称原始生产链已全面验证。证据见 `reports/m3/copernicus-source.json`。

EGM2008 使用离线、哈希绑定的 PROJ/NGA 网格，以 `h=H+N` 转为椭球高。[PROJ vgridshift](https://proj.org/en/stable/operations/transformations/vgridshift.html) 中显式使用 multiplier=+1，禁止可选网格和无网格近似回退；再次给已是椭球高的数据添加 geoid 会报错。网格类型和目标 EPSG:3855 也会检查。

水平坐标转到以接收点为中心的 WGS84 方位等距投影后，以最近原像元读取有界窗口。记录原窗口、原生像元间距估计、输出分辨率、scale/offset 和转换定义；保留 nodata，不调用展示用降采样。最多一百万输出像元、四百万源窗口像元，并限制原始存储块大小。详见 [Rasterio 窗口读取说明](https://rasterio.readthedocs.io/en/stable/topics/windowed-rw.html)。

## 与 M1 联动

`calculate_links(config, catalog, terrain=TerrainContext(...))` 将地形损耗写入唯一的 local 分量。调用前必须关闭原声明的 local loss，否则拒绝重复计算。接收点必须与地形网格原点一致；天线椭球高必须不低于当地 DSM/DTM 表面。高于 DSM 的距离不等于离裸地 AGL。

记录包括逐样本地形剖面、LOS、raw/used loss、来源和物理输入哈希（含 TLE 选择、配置及地形）。地形数据不充分时保留几何和未知预算，完整性标记为 false；不会把地形缺口解释成零损耗。地平线以下功率仍为 not_applicable。天顶当前明确返回未计算。

命令行支持：

```bash
bash scripts/python_geo.sh -m satellite_coverage.experiments.link \
  --config configs/m1_tle.yaml \
  --tle ../Satellite-Ground-Radiomap/data/starlink-2025-tle/2025-01-01.tle \
  --terrain configs/m3_copernicus.yaml --output output/m3-linked-new
```

该命令使用 M1 配置显式声明的天线椭球高（示例为 400 m），不自动替换为 DEM 高度。运行额外归档转换后的本地高程数组和转换来源；原 DEM 不修改。首次需将 EGM2008 网格下载到配置位置：

```bash
bash scripts/python_geo.sh scripts/fetch_egm2008.py --output output/geoid/egm2008-complete.tif
```

## 输入与输出

`geometry.terrain.TerrainGrid` 接收二维高程数组、像元分辨率、网格西/北边界、垂直基准和来源身份。坐标为当地东/北向米，高程必须已经转换为同一已声明基准下的米值；行向南递增。NaN 表示 nodata。网格数据冻结，不能事后修改输入身份。

`terrain_profile()` 沿指定方位进行最近像元采样，输出原始高程、距离、曲率修正、相对天线高度、仰角、采样地平线和限制地物距离。接收地面高度从同一 DEM 读取，再加 AGL。`horizon_profile()` 接受一组方位生成采样天空轮廓。

`geometry.cell_profile.cell_profile()` 提供新的像元区间方式：边界分别保留左右单侧高度，并取二次曲率下的区间内部地平线极值；额外点的间距不超过 `step_m`。返回区间与逐点身份，schema_version 为 2。此方式中步长大于像元尺寸不会跳过像元，但不提高源 DEM 分辨率，也不证明损耗极值已全部捕获。M1/CLI 使用 `sampling_method: cell_intervals` 启用；缺省 `uniform` 保留历史行为。示例已启用新区间方式。

`engine.terrain_link.evaluate_profile()` 给定仰角、斜距和频率，输出：

对于 `cell_intervals`，求值还包含每个区间内菲涅耳参数 v 的驻点候选。令投影距离为 d、带符号高度为 h、链路长度为 L，求解 `2h'd(L-d)-hd'(L-2d)=0`；使用归一化区间多项式求根。对于可由界限证明损耗为零或最大值位于已有左端点的区间，跳过求根。低于射线且投影位于接收机后方的点不参与前向刀刃求值，记录 `excluded_behind_receiver_points`，不再当作数据缺口；其他投影越界仍保留不适用状态。这是既定局部单刀刃模型的数值修复，不是多障碍真实传播验证。

- `blocked`：已知采样地物穿过直达射线；即使另有数据缺口，也保留这一阻挡证据。
- `clear_within_radius`：请求半径内的采样剖面未阻挡，不表示整个卫星路径无遮挡。
- `unknown`：未发现确定阻挡，但范围、nodata、接收高程或采样条件不足。
- 相对直达射线的带符号垂直净空、第一菲涅耳半径及单刀刃参数。
- 局部主导理想单刀刃的原始损耗、截顶后损耗及截顶标记；有数据缺口时正式损耗为空，不能代入零。

## 物理与范围契约

1. 原始地形输入不得预先添加曲率。`effective_radius_m=None` 关闭曲率；显式给出有效半径时，模块只应用一次局部 `d²/(2R_eff)` 修正。用户若使用 kR，需在调用条件中明确 k，不隐含假定标准折射。
2. 半径最多 100 km；有效半径至少 1000 km。这是局部二次曲率近似，不是全球地球几何或大气射线追踪。
3. 当前支持仰角 `[0,90)` 且卫星水平距离大于剖面半径的远端链路。近端发射机落入剖面范围时，返回范围不适用，需缩短剖面；天顶特殊路径尚未提供专用处理。
4. 最近像元采样保留原始分辨率。步长超过原生分辨率时标记采样不足；缩小步长只改善对该栅格的取样，不增加 DEM 的真实地物分辨能力，也不提供连续地形保证。
5. 地平线取已知样本仰角最大值。缺口存在时它最多是已采样证据的下界；不得据此宣称天空无遮挡。
6. 绕射采用局部主导单理想刀刃近似，依赖薄边缘和近轴假设。对多重山脊、圆钝山体及大角度遮挡不声称高保真。这里计算的是局部基线，不是全路径损耗。
7. 几何相切时 LOS 可以成立，但菲涅耳净空不充分，理想刀刃近似仍约为 6 dB；不能把 LOS 与零绕射损耗等同。

单刀刃近似依据 [ITU-R P.526-16](https://www.itu.int/dms_pubrec/itu-r/rec/p/R-REC-P.526-16-202511-I%21%21PDF-E.pdf) §4.1。旧版 `propagation.knife_edge_loss_db` 原样保留；新基线输出 signed clearance 和 raw/used loss，不修改旧地图结果。
