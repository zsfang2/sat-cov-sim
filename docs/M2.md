# 局部传播方向表与缓存

接口位于 `satellite_coverage.engine.direction_table`。当前内置 `TerrainLocalSolver` 复用已验收的主导单刀刃模型；`DirectionTable` 负责规则方向采样、查询和存储，不引入新传播公式。

```python
from satellite_coverage.engine.direction_table import DirectionTable, TerrainLocalSolver

# context 为 TerrainContext，receiver 使用经验证的椭球高。
solver = TerrainLocalSolver(context, receiver,
                            frequency_hz=14.5e9, slant_range_m=550000)
table = DirectionTable.build(solver, azimuth_step_deg=30,
                             elevations_deg=[0, 5, 10, 15, 20, 25, 30])
result = table.query(12, 7, method="bilinear",
                     expected_descriptor=solver.descriptor(), fallback_solver=solver)
path = table.save("output/my-direction-cache")
loaded = DirectionTable.load(path, expected_descriptor=solver.descriptor())
for chunk in loaded.query_batch([(0, 5), (360, 5), (None, 90)], chunk_size=64,
                                 expected_descriptor=solver.descriptor(), fallback_solver=solver):
    print(chunk)
```

## 存什么、何时失效

表中保存局部损耗 Quantity（dB）、raw/截顶/LOS/原因、有限半径契约、原方向样本及相邻状态边界标记。使用 float64 JSON，不含接收功率、FSPL、大气或天线增益。调用方仍使用 M1 的分量预算重组功率，不能把 FSPL 重复算进 local。

内置求解器描述符绑定地形数组哈希、来源/基准/网格位置、接收机坐标与椭球高、频率、斜距、曲率、半径、步长、截顶/采样设置、模型源码指纹、Python/NumPy 版本与平均功率约定。当前局部公式依赖有限斜距，斜距变化不能沿用同一缓存；不能暗中改成平面波。纯 EIRP 与接收增益不影响本地标量传播分量，保留在缓存外重组。

缓存键还包含方向轴、天顶保护角、格式版本。查询和重载必须提供期望描述符，不一致抛出 CacheMismatch；不能静默命中或用不同身份的求解器回退。改参数后可新建表，或使用新参数的直接求解器。通用 provider 需实现 descriptor()/evaluate(azimuth,elevation)，并如实声明全部依赖；自定义 provider 的物理正确性由实现者负责。

## 查询与边界

- 原样本点返回完整原响应，包括原有未知/不适用/失败；原样本精确重现不等于物理误差为零。
- 方位按 360° 周期归一化，网格覆盖完整 [0,360)。仰角只能在声明的有界规则网格内插值。
- `nearest` 选所在网格单元内最近角点；平局按较小方位/仰角索引固定选择。`bilinear` 在兼容角点上插值 raw，然后应用原 cap。
- 两种查询都检查参与单元的状态、LOS、cap 与范围契约。未知、失败、遮挡状态或截顶状态不同会回退，不能跨状态平滑。
- 缓存保存的 boundary 标记表示相邻样本状态不一致或本点不可用，并不是连续地形所有边界的认证。两个已知角点之间仍可能隐藏窄障碍，非样本查询的 accuracy 永远是 not_verified。
- 默认天顶保护角 89.9°，高于保护角或超出仰角域会请求直接计算；已有 M3 在正天顶返回 not_computed。地平线以下直接模型返回 not_applicable。
- 显式要求 `error_tolerance_db` 时，除原样本重现外一律回退，因为当前没有插值全域误差上界。该参数不能把一次诊断升级为业务认证。
- 返回实际方法、邻点索引与权重、有效域、缓存/求解器身份、回退原因。没有提供 fallback_solver 时返回 fallback_required 与 null 损耗。直接求解失败作为 failed 响应保留。

非法角度/非有限值、方法名、缓存身份或缓存格式直接抛错，不冒充一次有效模型查询。批量接口按块流式返回，合法请求顺序与逐条调用一致；非法请求会中断所在迭代，调用方应预先校验请求或捕获异常。

## 存储与资源

默认最多 100000 个方向样本，构建前检查；构建和批量查询的默认块为 256。查询表本体仍在内存，分块不会把它变成无限容量缓存。磁盘 JSON 默认读取上限 128 MiB、100000 个样本；校验内容哈希、输入身份、坐标、单位、状态、raw/used/cap 和有限范围契约。采用排他创建，不能覆盖原缓存；不存在自动删除损坏文件的动作。
