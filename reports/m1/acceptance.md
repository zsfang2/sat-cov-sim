## 实测结果

- 完整后端回归：**186 passed in 7.05s**，命令 `bash scripts/python_geo.sh -m pytest tests -q`。包含既有第一周、轨道窗口、DEM/API 测试，无跳过项。
- 固定 ECEF：3 个样本，全部已知功率，550 km / 14.5 GHz / 55 dBm EIRP / 0 dBi 接收增益 / 无附加损耗，结果均为 **−115.482397035 dBm**。
- 人工方向：5 个跨 UTC 日界样本，12 dBi 峰值、指数 2 的 cosine 方向图和固定 1 dB 大气损耗；3 个已知功率，另外 2 个地平线及以下点为 not_applicable。已知范围 **−110.502996948 至 −104.482397035 dBm**。
- 真实 TLE：NORAD 44714，2025-01-01 05:00 至次日 00:00 UTC，6,841 点；473 个已知条件功率，6,368 个几何不可见点保留。使用起点之前的元素，不使用未来历元；全部传播成功。
- 真实算例功率范围 **−129.288357550 至 −116.331106497 dBm**。天线高度 400 m、频率和功率为显式假设，不是 Starlink 实际链路规格。
- 独立 PROJ 地面 ECEF 对照误差 0 m；Skyfield 站心距离最大差约 **5.402e-8 m**、仰角 **2.885e-12°**、方位 **1.564e-12°**，功率重组差 **0 dB**。Skyfield 对照共享轨道传播，这些数字不代表真实轨道精度。

## 本轮发现并解决的边界问题

1. 已有轨迹 API 未对最大历元偏差进行同等检查，现与窗口计算保持一致。
2. 浮点 `ceil(duration/step)` 可能多生成一个终点，统一采样改为整数微秒刻度并测试亚秒边界。
3. 超大步长可能在构造 timedelta 时溢出，现直接生成起止点。
4. 分量失败不能只标记功率 failed 而让阶段运行显示成功；统一结果将受影响样本和完整性标记为失败。
5. 两种等价功率输入应产生相同物理结果，但配置哈希仍应不同，相关测试分别验证数值等价和输入可追溯性。

## 下一阶段：M3 基础环境模型

按原计划 M0 → M1 → M3 → M4 → M2 → M5 → M6 继续。下一项是地平线剖面与基础地形遮挡：明确半径、曲率、采样步长、nodata/范围不足策略，然后验证平地、单山脊和步长收敛。现有 DEM 单位/垂直基准仍无文件级证据，不能直接参与可信真实高度计算；可先用有明确高度基准的人工地形推进基础实现。

完整 E1 的复杂地形和直接计算/缓存重组对照依赖后续 M3/M2，当前尚未完成。真实波束、气象模型、服务调度、持久化任务系统及批量参考数据集也不在本次验收范围。demo 待阶段基础验收后单独安排，本轮未增加展示能力。
