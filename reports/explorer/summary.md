## 已实现

- TLE 服务器路径、弹窗文件浏览，以及浏览器本机文件上传；两行/三行格式、校验和和编号检查。
- 轨道记录解析、完全重复元素去重、同一卫星历元选择及过期/未来历元说明。
- 指定 UTC 起止时间、最低仰角、点位或矩形区域、椭球高；默认区域任一采样点可见。
- 单星逐点窗口、区域并集/交集、星座覆盖区间、边界截断、后台进度与取消。
- 时间轴、分页窗口表、卫星筛选、仰角曲线、星下点轨迹，以及 JSON / CSV 导出。
- 真实 GeoTIFF 元数据、DEM 色带与纹理、缩放/平移、全范围预览、点选终端和使用视图作为区域。

## 边界与备注

- 计算结果是几何仰角可见性，不包含地形/建筑遮挡、大气折射、波束调度或通信服务资格。
- DEM 仅展示；垂直基准与单位未知时不猜测，不自动转换为终端椭球高。
- 区域结果只针对网格采样点，不代表连续区域每一点；“全部采样点”星座覆盖可能使用不同卫星。
- 数值事件搜索容差与真实 TLE 预测误差不同；显示曲线的 721 个采样点不用于替代窗口求解。
- 历元选择允许在没有历史元素时使用最早未来元素，但会明确标记；适用于这个历史探索工具，不等于严格无前视的在线策略。
- 应用仅监听本机地址；远程使用需端口转发。未部署公开站点，也未自动修改远程 Git 分支。
