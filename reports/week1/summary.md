## 真实数据发现

- 四个上游 256×256 数组的哈希均与其 manifest 一致；存储复合数组与 L1+L2+L3 的最大重组差为 **0 dB**。这是算术一致性，不能证明原模型正确。
- L1 已包含减去发射增益的净损耗，不能按纯传播损耗再次加同一发射增益；接收功率、FSPL/大气等细分地图没有在这组保存结果中单独恢复。
- 上游记录 IONEX 与 ERA5 回退，卫星 metadata 为空；这些限制完整保存。上游 L2 全零不能解释为“地形没有影响”，本仓库 CF-01 的适用性也不能自动套用到另一个生成器。
- DEM 全文件 SHA-256 与上游 manifest 一致，原生像元间距为 `1/3600°`，不是统一 30 m 的投影格网。窗口原始值为 395–426，声明 nodata=0，当前窗口有效比例 100%。垂直单位未证实时不把这些数值直接标为已认证的米制高度。
- 候选点到窗口边缘的最小轴向诊断距离约 **817 m**。未冻结剖面半径，故地平线范围充分性仍为 `undetermined`。

完整证据见 [sample-audit.json](sample-audit.json)。原始窗口和掩码位于本地 `runs/audit-final/`，由复现命令重新产生，大数组不进 Git。

## 实测开销与资源预算

CPU：Intel Xeon Platinum 8562Y+；解析循环为单执行线程。每项解析计算先预热，再测 5 组、每组 100 次，表中为每次调用耗时；完整细节见 [performance.json](performance.json)。

| 操作 | 实测值 | 范围/口径 |
| --- | --- | --- |
| 人工局部几何 | 中位数 2.44 μs | 2.39–2.56 μs |
| FSPL | 中位数 5.05 μs | 5.00–5.54 μs |
| 完整链路记录计算 | 中位数 94.97 μs | 86.66–111.11 μs；含组装记录，不含输出写盘 |
| 约 8.6 GiB DEM 全文件哈希 | 最终审计 6.56 s | 初次观测 9.14 s；操作系统页缓存未控制，不作为冷/热基准 |
| 原生 64×64 DEM 窗口读取与审计 | 约 0.050 s | 单次观测，含坐标/元数据处理 |
| 解析运行 JSON 写出累计 | 约 0.0021 s | 不含最后的资源记录和 artifact 清单写出 |
| 解析/审计进程峰值 RSS | 约 199.5 / 212.5 MiB | 含已加载依赖；不是纯数组内存，也不是全机占用 |

当前规模适合 CPU 小样本开发，未显示需要 GPU 的依据。四个数组合计约 1 MiB，DEM 只读小窗口；完整哈希以流式方式执行。

这些数值不能外推完整地形传播、多方向建表或多过境总工时。八周计划仍保留为待更新估计；第二周取得地形剖面和逐点几何计时后，再冻结扩大实验的预算。不要用本周微秒级自由空间结果估算尚未实现的地形算法。

## 复现

```bash
env PYTHONPATH=src python -m satellite_coverage.experiments.pilot validate-data --config configs/pilot.yaml --output output/week1-audit

env PYTHONPATH=src python -m satellite_coverage.experiments.pilot run --config configs/pilot.yaml --output output/week1-b
```
